
# 🔐 CyberSecure Challenge – Promoting Cyber Hygiene

This repository contains original infographics created for the **CyberSecure Challenge** organized by **Saint Louis University** in 2025. The goal of this project is to promote cyber hygiene and raise awareness about essential cybersecurity practices among users of all ages.

## 📁 Contents

- Infographic 1: Creating and Managing Strong Passwords (PDF)
- Infographic 2: Identifying Phishing and Social Engineering Attacks (PDF)
- Infographic 3: Adopting Safe Browsing Habits and Online Behavior (PDF)

## 🧠 Project Overview

The **CyberSecure Challenge** is tailored for learners at various levels, helping participants understand their role in preventing cybercrime and promoting digital safety. The competition encourages creative thinking, teamwork, and innovation in addressing real-world cybersecurity challenges.

Through this project, users can learn about:
- How to create strong, secure passwords.
- How to detect and prevent phishing and social engineering attacks.
- Safe browsing habits and responsible online behavior.

## 🎯 Key Themes Covered

- **Password Security**
- **Phishing & Social Engineering Awareness**
- **Safe Browsing Practices**

## 📌 Submission Format

All submissions are original infographics designed in A4 size (PDF format), with a focus on clarity, relatability, and actionable tips.
